# Music Admin (local)
From repository root: `pnpm --dir apps/web exec node scripts/music-admin.mjs`. Open http://127.0.0.1:4178. Stop with Ctrl+C. Do not expose this server publicly. No new dependencies or public routes.
Create or open a release, fill bilingual fields and MDX, paste YouTube URL or ID, enter local artwork paths (copy artwork into apps/web/public yourself), and edit structured arrays in JSON fields. Validate before saving. Drafts must satisfy existing catalog metadata and original-track requirements. Published entries must satisfy all existing rules including YouTube, artwork, editorial bodies and authorized downloads for edits/mixes. Save changes only to local files; review git diff. Do not mark releases published before R2 delivery is ready. No MDX compilation, artwork upload, preview rendering or R2 connection in this increment. Do not run concurrent admin instances or edit the same release externally while saving. Slug/category changes and deletion are intentionally unsupported.
