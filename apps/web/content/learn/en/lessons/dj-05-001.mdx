A dependable DJ library starts with a deceptively simple question: **where does the music come from, and what are you allowed to do with it?** Searching a catalogue, buying a download, receiving a promotional file and accessing a song inside DJ software can all result in a playable track, but these routes have different technical and contractual limits.

## What you will learn

1. Distinguish purchases, DJ record pools, artist promos, free licensed downloads and integrated streaming.
2. Identify whether you receive an actual audio file or merely temporary platform access.
3. Check a track's version, technical characteristics and provenance before adding it to a performance library.
4. Build a repeatable acquisition checklist without assuming a download means unrestricted reuse.

## 1. Music access is not the same as ownership of a file

<AccessVsFileEn />


A **downloaded audio file** is a file you can locate and back up, subject to the terms under which you obtained it. **Streaming access** generally means that a service makes a track available under an account, integration and other restrictions. An application may show both sources in the same library interface, but they are not interchangeable.

If a streaming integration supports DJ playback today, that does not automatically grant offline access, recording, redistribution, USB export or compatibility with standalone players. Check the provider's current documentation before depending on it at a show.

## 2. Legitimate ways DJs obtain tracks

<SourceLandscapeEn />


| Source | Typical benefit | Check before relying on it |
| --- | --- | --- |
| Digital music stores | Individual tracks or releases as audio files | File format, version, availability and licence terms |
| DJ record pools | Downloadable promos, edits or curated releases for eligible members | Membership eligibility, download rights and usage restrictions |
| Artist or label promotions | Direct access to releases intended for promotion | Whether the file may be used, shared or redistributed |
| Licensed free downloads | Low-cost discovery and legally shared material | The exact permission and any attribution requirement |
| DJ software streaming integrations | Large catalogues and rapid discovery | Subscription, region, network, hardware support and recording/export limits |
| Your own authorised recordings | Control over your own audio material | Rights to underlying samples, performances and compositions |

A source being 'free' is not enough to show that redistribution or public performance is permitted. Likewise, buying a music file does not automatically resolve venue, public-performance, broadcast or online-upload rights. The full legal discussion belongs to Module 12.

## 3. Check the exact version, not just the song title

<VersionChooserEn />


The same song may appear as a radio edit, extended mix, clean edit, explicit version, instrumental, acapella or a remaster. Distinguish an official release from an unverified upload. Note the artist, title, mix/version, release and source so you do not discover during a performance that the file starts unexpectedly, cuts out early or contains a different arrangement.

Do not assume that two files with the same track title have identical intros, lengths or loudness. Before importing, audition the start, the middle and the ending at a safe level.

## 4. Audio quality and provenance

<QualityProvenanceEn />


A larger file or a high bitrate label is **not proof of genuine audio quality**. A lossy file converted to WAV remains lossy in origin; the conversion cannot reconstruct discarded details. Use trusted sources, pay attention to suspicious artifacts, and retain the original file when possible. The next lesson compares formats and compression in more detail.

For a practical library, keep a small, consistent set of formats that your main DJ software, backup player and export target can all handle. Compatibility matters alongside fidelity.

## 5. Download, streaming catalogue and a DJ library are different things

<SourceToLibraryEn />


A store purchase may provide a file in a Downloads folder; it is not automatically organized or backed up. Importing the file into DJ software usually creates a **database reference**, and may not move or copy the original. If the underlying file later moves, the software can display a missing-track warning.

For streaming integrations, a catalogue entry may be playable through the service without existing as a local file that you can export. Never rely on the appearance of a track in a playlist as proof that it is available without internet.

## 6. A safe acquisition workflow

<AcquisitionChecklistEn />


1. Decide why you need the track and which specific mix or edit fits that purpose.
2. Identify a legitimate source and check the permitted use.
3. Verify the exact release, duration, format and available download options.
4. Obtain the audio file only when the source actually permits it.
5. Play the file locally and listen for corruption or obvious quality problems.
6. Save it to a consistent location and record useful metadata.
7. Import into your DJ application's library and confirm it loads.
8. Back up the audio and relevant preparation data before relying on the track at an event.

## 7. Streaming-specific decisions

<UsagePermissionMatrixEn />


Streaming can be useful for discovery or supported live performance, but its operational risk depends on the service and the event. Verify whether your account and DJ application support the integration, whether your hardware works with that source, and whether a connection is required. If a function is unclear, treat it as unavailable until verified.

For events where connection loss would interrupt the show, prepare an authorised local fallback, test it with network access disabled and document any feature differences.

## 8. Common mistakes

- **Assuming everything in a DJ playlist is a downloadable file.** Some entries are cloud references.
- **Treating conversion as quality improvement.** Re-encoding cannot restore missing audio information.
- **Ignoring track versions.** A radio and an extended mix may need different cue preparation.
- **Confusing personal listening with public or online use.** Rights and terms vary by context.
- **Saving files only in a temporary folder.** A library reference may break when files are moved or deleted.

## Practice: source and readiness audit

<SourceAuditWorksheetEn />


Choose **five tracks** from different sources that you are permitted to access. For each, write down the source, release/version, whether a local audio file exists, the available format, streaming dependencies, and whether you successfully loaded it offline in your DJ software. Mark uncertainty explicitly rather than assuming a missing licence or export restriction is harmless.
