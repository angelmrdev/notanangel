Construye tu colección como un sistema **fiable, localizable y portable**, no como una acumulación de carpetas. Este módulo conecta el acceso legítimo a la música y su calidad con la organización y preparación de temas.

## Objetivos de aprendizaje

- Comparar fuentes legítimas y comprender las limitaciones de uso.
- Comprobar formatos y metadatos antes de importar.
- Organizar archivos y playlists sin perder referencias.
- Revisar beatgrids, preparar cues y aplicar etiquetas útiles.
- Proteger archivos y datos de preparación mediante copias verificadas.

## Secuencia recomendada

Completa las nueve lecciones en orden. Empieza con un grupo reducido de canciones que puedas usar legítimamente y conserva una copia antes de mover archivos o modificar etiquetas. La planificación avanzada de sesiones pertenece a un módulo posterior.

## Antes de comenzar

Anota dónde guardas los archivos, dónde almacena el software DJ su base de datos y qué servicios de streaming tienes integrados, si los hay. No confundas una caché de streaming con un archivo de audio portable.
