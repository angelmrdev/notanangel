# Roadmap

T08-A engine; B interface; C batch/export; D public release. Then Music deployment. Future milestones:

- [T08-AUDIO-METADATA-EDITOR](T08-AUDIO-METADATA-EDITOR.md): MP3/WAV tags, artwork, playback, batch edits, presets, JSON and ZIP export. Initial engine supports ID3v2.3 and RIFF INFO only; extend before release.
- [T09-AUDIO-VISUALIZATION](T09-AUDIO-VISUALIZATION.md): Local playback, overview and detailed waveform, zoom, spectral RGB and seek. Reuse existing audio workers.
- [T10-DJ-TRACK-EDITOR](T10-DJ-TRACK-EDITOR.md): BPM/key analysis, manual beatgrid and downbeat, eight hot cues, memory cues, loops and versioned projects.
- [T11-DJ-LIBRARY-MANAGER](T11-DJ-LIBRARY-MANAGER.md): Local folder import, search, filters, playlists, duplicates, statistics and batch editing.
- [T12-REKORDBOX-LIBRARY-VIEWER](T12-REKORDBOX-LIBRARY-VIEWER.md): Read-only XML import, collection, playlist tree, cues and tempo markers when present. No direct database access or streaming audio.
- [T13-DJ-INTEROPERABILITY](T13-DJ-INTEROPERABILITY.md): Export compatible XML, validate round trips in actual Rekordbox versions; never overwrite original library.
- [T14-ADVANCED-AUDIO-ANALYSIS](T14-ADVANCED-AUDIO-ANALYSIS.md): Estimated phrases, structure, energy, loudness and harmonic recommendations; measure accuracy before claims.
